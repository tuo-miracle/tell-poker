# 教訓（MR 德州撲克）

- **派 worktree agent 前，先 commit 它要用的檔案**（Claw Hand 時已記過，2026-10-12 再犯：92 段錄製還沒 commit 就派了調參 agent，派工單還寫「已 commit」）。
  做法：派工前跑一次 `git status --short`，有任何與任務相關的未 commit 檔案就先 commit；派工單裡關於「已在 main」的陳述，要在派之前用 `git log` 確認過才寫。
- **用截斷的輸出下結論**：查 registry 版本時用了 `[-3:]` 取未排序清單的最後 3 筆，誤判 OpenXR 1.18.0 不存在。要確認「有沒有」時要完整列出或明確搜尋。
- **Quest 的捏合強度（OVRHand.GetFingerPinchStrength）在真機上封頂 0.70**（92 段錄製實測）；門檻寫「> 0.7」永遠不會觸發。合成資料測不出這種事，真實錄製才抓得到。
- **錄製手勢前，桌上要畫出目標物**（籌碼堆、牌）。沒有目標時，玩家會憑感覺做動作，與位置相關的手勢錄製就沒有參考價值。
- **視野檢查只從一個固定的眼睛、只查「字被角色擋住」**：Editor 全過，實機（頭戴裝置放在桌上，眼睛低 0.2 m）字幕卻浮在角色身上（2026-10-14）。
  做法：放在 3D 空間的 UI 要對一組眼睛位置（高度、前後、轉頭）檢查，而且雙向檢查：字被擋住、字蓋住別的東西（從眼睛穿過字的視線延伸出去打到什麼）。
