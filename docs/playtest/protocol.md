# 試玩流程（給 Max 帶朋友試玩用）

目的：用證據回答三件事——**新手能不能自己上手**、**會不會覺得「AI 在讀我」**、**玩完想不想再玩**。每位試玩者約 15 分鐘。

## 開始前（2 分鐘）
1. 頭盔充電、Wi-Fi 連上（語音要網路）、音量調到一半以上。
2. 刪除存檔讓教學重新出現：手腕選單 → How to play → Replay tutorial（或請 Claude 用 adb 清存檔）。
3. 告訴試玩者**只說這一句**：「這是一個用手玩的撲克遊戲，照遊戲裡的指示玩，想到什麼就講出來。」
   - 不要示範手勢、不要解釋規則、不要提「AI 會讀你」——我們要看他們自己能不能發現。
4. 試玩者坐在桌前，戴上頭盔。

## 觀察（玩的時候，你只看不教）
在紙上或手機記下：
| 時間點 | 要記的 |
|---|---|
| 教學 | 卡在哪一步、卡多久；有沒有自己看懂示範手 |
| 第一次被 AI 點破 | 表情或反應（笑、驚訝、沒反應、困惑） |
| 第二手騙 Rocco | 有沒有照做、騙到時的反應 |
| 正式牌局 | 有沒有主動盯著 AI 看、有沒有對 AI 講話、有沒有手勢一直失敗 |
| 任何時候 | 試玩者自言自語說的話（原話最有價值） |

卡住超過 1 分鐘才可以幫忙，而且要記下「我幫了什麼」。

## 玩完後的問題（照順序問，記原話）
1. 「用一句話講，這個遊戲在玩什麼？」（聽他們有沒有提到讀心／被讀）
2. 「有沒有哪個時刻讓你覺得『哇』？」
3. 「AI 有沒有讓你覺得它在觀察你？什麼時候？」
4. 「哪個動作最難做、最讓你挫折？」
5. 「1–10 分，你多想再玩一局？為什麼不是更高？」
6. 「你懂撲克嗎？」（不懂／一點／常玩）

## 結束後交給 Claude
- 你的筆記（照片也可以）。
- 告訴 Claude 試玩的大概時間，Claude 會從頭盔 log（`[Playtest]`、`[LiveTalk]`、`[Read]`、`[Tutorial]`、手勢 trace）算出：上手時間、第一次下注時間、騙到 Rocco 的時間、每個手勢的失敗次數、卡住的位置。

## 判讀（3 位以上試玩者）
- **繼續撲克＋雙向讀心**：≥ 2 位在問題 1 或 3 自己提到「讀心／被看穿／騙 AI」，且問題 5 平均 ≥ 7。
- **要大改**：沒有人提到讀心，或問題 5 平均 < 5 → 和 Max 討論方向（核心是否沒傳達出來，還是本身不好玩）。
- **手勢**：任一手勢讓 ≥ 2 位卡住超過 1 分鐘 → 列為最優先修正。
