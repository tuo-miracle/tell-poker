# Hank 臉部 wrap 驗證計畫（做法二，2026-10-29）

## 目標
用 1 天驗證：把「有完整表情系統的標準頭」貼合到 Tripo 生成的 Hank 臉上，讓他能**真的眨眼、張嘴、轉眼球**，並在 Quest 3 上看效果。依結果決定 9 個角色要不要全部換成寫實。

## 成功標準（全部要過）
1. 眨眼能完全閉合，沒有破圖。
2. 張嘴看得到口腔和牙齒，看不到空洞。
3. 眼球能轉，看得出他在看誰。
4. 從玩家的距離（約 1 m）看，臉還認得出是 Hank（長相、膚色、鬍子）。
5. 臉和原本的頭（帽子、耳朵、脖子）接縫在 1 m 外看不出來。
6. Quest 3 上 4 人同桌維持 72 fps。

## 步驟
- [ ] 1. 選標準頭：查授權、有沒有眼口、ARKit、面數（研究 agent → `docs/research/2026-10-29-base-head-for-wrap.md`）
- [ ] 2. 對位：用 MediaPipe 在 Tripo 頭和標準頭的正面渲染圖上各找特徵點，投回 3D，算剛體＋縮放對齊
- [ ] 3. 變形貼合：以特徵點為約束做非剛性變形（RBF 或 Laplacian）＋ shrinkwrap 貼表面；眼球、牙齒跟著眼眶和下巴走
- [ ] 4. 換臉：只換「臉罩」區域（額頭到下巴、兩耳之間），保留 Tripo 的頭頂、帽子、耳朵、脖子；接縫邊緣做混合
- [ ] 5. 投貼圖：把 Tripo 貼圖 bake 到標準頭的 UV（selected-to-active）；眼球用標準頭自己的虹膜貼圖，口腔用標準頭的材質
- [ ] 6. 驗證渲染：中性、眨眼、張嘴、眼球左右看、微笑、皺眉的特寫和 1 m 距離圖
- [ ] 7. 接到 Unity 預覽分支（`vr-poker-hank`），表情對應改用 ARKit 全套（含 jawOpen、眼球骨頭），上機截圖並量 fps

## 停損
- 同一步驟最多試 2 輪，第 3 次失敗就停下回報。
- 第 3 步貼合效果明顯失敗（臉型不像 Hank、五官錯位）→ 停，改評估做法一（直接在 Tripo 模型上補眼球、眼皮、口腔）。
- 找不到授權能商用的標準頭 → 停，回報選項。
